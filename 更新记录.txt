2026.3.27 更新日志说明
一、平台兼容性

项目	说明

1、Windows 10/11 支持	全面兼容 Windows x86_64 平台，可在 Windows 下直接编译运行

2、CPU 平台检测	Windows 下通过注册表读取 CPU 厂商（Intel/AMD/兆芯/海光），Linux 下保留 /proc/cpuinfo 方式

3、开机自启动	Windows 使用注册表 HKCU\...\Run 实现，Linux 保留 systemd 用户级服务

4、Qt 版本适配	兼容 Qt 5.x 和 Qt 6.x（修复 QIODevice 头文件缺失、QRegExp → QRegularExpression、QChar::isLetterOrNumber）

5、自动部署	.pro 新增 windeployqt 自动部署步骤，Windows 编译后自动复制所需 DLL

二、UI 界面优化

项目	修改前	修改后

1、开机启动	两个独立按钮「开机启动」「取消开机启动」	单个勾选框，启动时自动检测并同步状态

2、窗口置顶	默认置顶，无法切换	新增「窗口置顶」勾选框，可自由开关，切换时窗口大小保持不变

3、已连接客户端	独立面板显示在线客户端列表	已移除，唤醒配置列表显示空间扩大

4、唤醒配置列表	与客户端列表左右并排，空间受限	独占整行，通过分割器与日志区域上下分布，支持大量设备滚动查看

5、表格列宽	列宽不均匀，清除操作列过宽	清除操作列缩窄至 70px，MAC 地址 150px 完整显示，最后唤醒时间 190px 完整显示

6、滚动条	整行跳跃滚动	逐像素平滑滚动，步长 30px

7、在线/离线状态	客户端 ID 后追加 (在线)/(离线) 标识	已取消状态监控，直接显示客户端 ID

三、功能增强

项目	说明

1、唤醒配置持久化	所有唤醒配置自动保存到 wake_configs.ini（exe 同目录），软件异常崩溃重启后自动加载，客户端无需重新连接配置

2、MAC 地址输入优化	仅需输入 12 位十六进制数字（如 001122AABBCC），后台自动补全冒号格式化为 00:11:22:33:44:FF；格式错误时弹出明确提示并清空输入框

3、窗口大小稳定性	窗口置顶勾选/取消切换时，保存并恢复窗口位置和尺寸，不再出现窗口跳动
